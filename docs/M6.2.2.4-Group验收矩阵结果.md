## 补充断言

每个拒绝用例至少覆盖：

1. `ok=false`；
2. Factory 深比较不变；
3. `saveFactory` / `saveCount` 为 0；
4. 无 `ok=true` 确认；
5. 拒绝后仍可处理后续合法请求（Vitest `a valid request after a rejected one still works`）。

## 关键实现说明

- 重复键按规范化 `periphId#slot` 比较；流体槽位使用 `periphId#fluid`，不与普通 slot 混用。
- Batch 的归属校验在全部 child 执行完、保存前进行，因此合法 split 的临时重叠可以通过，最终重复则整批丢弃。
- G-13 的选择是“拒绝”：物品组必须带正整数 slot；这是明确证据，不是默认行为。
